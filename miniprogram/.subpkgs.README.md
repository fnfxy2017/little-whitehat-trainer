# 分包(subpkgs/)规划占位

阶段 1+2 阶段:不创建分包目录,等阶段 5 真正写分包页面时再建。

阶段 5 会重建以下结构:
```
subpkgs/
├── act2/   第二幕(C4-C9 + X1-X3)
├── act3/   第三幕(X4-X6 + M1-M3)
├── act4/   第四幕(D1-D8 + Y1-Y3 + M4)
├── act5/   第五幕(E1-E12)
├── act6/   第六幕(F1-F4 + F6-F7)
└── act7/   第七幕(G1-G12)
```

到时同步在 app.json 中加回 subpackages 配置和 preloadRule 预下载策略。
